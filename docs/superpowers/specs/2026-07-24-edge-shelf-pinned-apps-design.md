# Edge Shelf Pin 常驻应用设计

## 目标与顺序

允许用户从完整、支持多开身份的应用目录中选择 1–3 个常驻应用。侧边栏展开后的固定区顺序为：录音（若开启）、截图、Pin 应用；最近/固定应用列表位于其后并独立滚动。

## 数据模型

- `ShelfSettings.pinnedApps: List<AppInstanceKey>`，最多 3 项。
- 使用完整的包名、用户序列号和组件名保存，原应用与应用多开实例可分别 Pin。
- 规范化时剔除无效键、按完整 key 去重并截断到 3 项。
- 目录更新后以现有 rebind 规则绑定组件；无法解析的项暂不显示但保留设置，以便工作资料/多开空间重新出现后恢复。

## 内容解析

- `ShelfContent` 单独返回 `pinnedApps`。
- Pin 项从最近、全部与固定的滚动内容中按完整 `AppInstanceKey` 精确去重，避免同一实例重复出现。
- 同包不同用户序列号不去重，确保多开实例保持可见。

## 管理界面

- 复用应用选择器并引入 `PickerPurpose.FAVORITES/PINNED`。
- Pin 模式显示“已选 x/3”；达到 3 项后，未选中的行禁用但已选项仍可取消。
- 保存顺序遵循已有选择优先、随后按应用目录顺序补入的确定性规则。
- 设置页显示当前数量和“管理常驻应用”入口；允许保存 0 项，首次选择时文案推荐 1–3 项而不强迫选择。

## 侧边栏视觉

- Pin 图标沿用原应用图标尺寸，并在右上角绘制低调翡翠绿 Pin 角标。
- 固定区不随下方列表滚动，点击反馈与普通应用一致，仍优先尝试窄比例小窗。
- 固定区和滚动区之间仅用留白/细分隔语义，不增加宽度或厚重卡片。

## 验收

1. 0、1、2、3 项均正确布局，第 4 项不可选择。
2. Pin 项始终位于工具下面，滚动应用列表时保持可见。
3. Pin 实例不会在下方重复；原应用与多开应用可同时存在且启动身份正确。
4. 重启应用和设备后选择与顺序保持。
