# Edge Shelf 一键截图与截图库设计

## 目标

在 Android 11（API 30）及以上设备提供真正的一键全局截图：用户点击侧边栏截图图标后，侧边栏先以现有非线性动画收回，约 260ms 后捕获屏幕，避免把侧边栏本身写入图片。截图可在界枢主界面查看缩略图、预览元数据并逐条删除。

## 权限与兼容

- 使用 `AccessibilityService.takeScreenshot`，服务仅声明截图能力，不读取窗口内容、不监听按键、不执行手势。
- 辅助功能未开启时不伪装成功：收回侧边栏并提示用户前往系统辅助功能页授权。
- API 29 保留应用安装能力，但显示设备不支持一键截图；不退化到每次弹系统确认框的 MediaProjection。
- 辅助功能服务连接状态通过进程内 StateFlow 暴露给设置页和侧边栏。

## 存储

- 目标集合：`MediaStore.Images`。
- 相对目录：`Pictures/EdgeShelf/`。
- 文件名：`EdgeShelf_yyyyMMdd_HHmmss_SSS.png`。
- 写入期间使用 `IS_PENDING=1`，PNG 压缩成功后再发布；失败时删除未完成条目。
- 截图库查询同时校验相对目录、文件名前缀和 MIME 类型，只展示本功能生成的 PNG。
- 删除仅针对所选 MediaStore URI，不申请广泛照片读取权限。

## 界面

- 在设置页加入“截图”状态行和辅助功能授权按钮。
- 截图库使用与录音库一致的 20dp 暖白卡片、翡翠绿强调色和克制原生排版。
- 列表展示缩略图、时间、分辨率与文件大小；点击缩略图打开沉浸式预览。
- 删除必须二次确认；成功后即时从列表移除并显示 Snackbar。
- 空状态、加载失败、截图失败都有明确文案，不以空白代替状态。

## 状态与故障处理

- 截图请求串行化；上一请求未结束时忽略重复点击。
- 服务回调成功后在 IO 线程复制硬件 Bitmap 并写入 MediaStore。
- 保存完成后广播/状态序号触发设置页刷新。
- 屏幕处于锁屏或 AccessibilityService 不可用时返回失败，不创建空文件。

## 验收

1. 授权后从任意应用一键截图，截图不包含展开的侧边栏。
2. 图片出现在 `Pictures/EdgeShelf` 和应用截图记录中。
3. 可查看缩略图、打开预览、取消删除、确认删除。
4. API 29 与未授权状态不崩溃且有明确引导。
