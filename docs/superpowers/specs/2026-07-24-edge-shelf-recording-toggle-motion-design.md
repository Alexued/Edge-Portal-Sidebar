# Edge Shelf 录音开关与状态动效设计

## 行为

- 新增 `recordingEnabled` 设置，默认开启，升级用户保持现有行为。
- 关闭开关时，若正在录音则先停止并保存，再从侧边栏移除录音入口；录音记录库仍然可见、可播放和删除。
- 重新开启后入口恢复在侧边栏第一位，不影响截图和应用内容。
- 侧边栏高度随工具数量重新计算，不为空入口预留高度。

## 动效语言

关键词：安静、精确、流体。动效只改变图标内部绘制与透明度，不改变布局尺寸，因此不会推动下方内容。

- 开始过渡：360ms，`cubic-bezier(0.16, 1, 0.3, 1)`。麦克风轮廓缩至 0.88、淡出，同时停止方块由 0.72 缩放并淡入。
- 录音中：1.25s 循环呼吸，使用正弦缓入缓出；一至两层低透明度红色圆环从 0.86 扩至 1.10，峰值透明度不超过 22%。
- 停止过渡：280ms，使用同族收束曲线；呼吸环先消散，麦克风轮廓平稳恢复。
- STARTING/STOPPING 使用降低饱和度的中间态，不旋转、不弹跳。
- 当系统关闭动画（`ValueAnimator.areAnimatorsEnabled() == false`）时直接显示清晰静态状态，不启动循环重绘。

## 性能

- 动画由单个 ValueAnimator 驱动，仅在录音活动或状态切换期间 `postInvalidateOnAnimation()`。
- 不分配逐帧 Bitmap/Path；复用 Paint 与 RectF。
- 页面退到后台、View 不可见或录音结束后停止循环，避免无意义耗电。

## 验收

1. 开关关闭时侧边栏无录音图标且没有空白槽位。
2. 录音中图标有低振幅、无跳动的呼吸反馈；开始与停止均为非线性过渡。
3. 快速重复点击不会产生多个录音实例或多个动画器。
4. 系统禁用动画时功能仍可识别、可操作。
