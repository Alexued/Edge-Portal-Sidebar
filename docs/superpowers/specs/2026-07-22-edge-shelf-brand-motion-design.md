# Edge Shelf 品牌与动效设计

## 状态

- 日期：2026-07-22
- 状态：用户已批准设计
- 范围：设置页版本信息、应用品牌图标、中文名称、侧栏展开收起动效、应用呼出反馈

## 目标

让 Edge Shelf 在设置页和系统启动器中拥有一致的科幻品牌识别，同时让侧栏呼出从突然撑开变为克制、连续、可预测的交互。高频操作必须保持响应速度，系统关闭动画时仍要保留清晰的最终状态。

## 品牌决策

中文短名使用“界枢”。设置页标题使用 `Edge Shelf · 界枢`，桌面图标、通知标题和服务文案使用“界枢”。原来的“边缘架”不再出现在面向用户的主要品牌位置，但历史兼容文案不需要迁移数据。

主图形是方向中性的双侧界门和中心光隙。左右镜像结构表达从任一屏幕边缘进入，不把品牌绑定到当前侧栏位置。全彩图标使用墨绿黑 `#101816`、翡翠 `#35A982` 和冷白 `#EAF7F2`，不使用渐变和细碎装饰。该母图形派生以下资源：

1. Android 26+ adaptive foreground/background
2. Android 33+ monochrome 图标
3. 旧版圆形启动器图标
4. 24dp 通知图标
5. 设置页 Header 标志

所有派生资源保持相同的中心光隙和双侧轮廓，小尺寸版本减少细节但不改变语义。

## 版本信息

版本号从当前 `1.1.2` 提升到 `1.2.0`，versionCode 提升到 5。设置页显示 `v1.2.0`，数据来源为构建生成的 `BuildConfig.VERSION_NAME`，不在 UI 文案中硬编码。

Header 左侧文字区域包含标题、副标题和版本元数据。宽屏时版本号与副标题保持同一基线，间距约 8dp；窄屏或 fontScale 大于 1.2 时版本号换到下一行。版本号使用 `labelMedium`、中等字重和 `onSurfaceVariant`，不使用胶囊背景，避免与右侧品牌标志竞争。

`MainActivity` 负责读取并传入版本字符串，`EdgeShelfScreen` 和 `Header` 只负责渲染。Header 左侧使用 weight 和最小间距，确保标题不会与 38x58dp 标志重叠。中英文资源分别维护标题、短名、副标题、版本辅助文本和无障碍描述。

## 动效语言

动效人格为“克制精致”：有明确的非线性节奏和轻微错峰，但不使用弹簧回弹或长时间电影式延迟。

### 展开

- 触发判定继续使用 24dp。
- 视觉展开行程独立为 72dp，避免达到判定阈值时面板已经瞬间完成。
- 面板完成展开的基准时长为 360ms。
- 展开曲线使用 `PathInterpolator(0.22, 0.0, 0.20, 1.0)`。
- 用户直接拖动时，面板进度跟随手指；松手后只补完剩余距离。

### 内容入场

- 面板稳定展开后 72ms 开始内容入场。
- 每个应用按照列表顺序错峰 16ms，最多累计 96ms。
- 每个图标的局部时长为 180ms。
- 初始状态为透明度 0、缩放 0.92、沿当前侧边方向偏移 10dp。
- 终态为透明度 1、缩放 1、偏移 0。
- 添加按钮、空状态和加载状态使用同一内容节奏，但不创建独立循环动画。

### 收起与呼出应用

- 点击外部或主动收起使用 250ms 的 `PathInterpolator(0.40, 0.0, 0.60, 1.0)`。
- 内容先在约 100ms 内淡出并向边缘移动 4dp，面板随后完成收拢。
- 点击应用时，被点击图标先做一次短促高亮和轻微缩放，约 40ms 后发起启动请求，同时侧栏开始收起。
- 目标应用自由窗的最终转场由 Android/HyperOS 控制。Edge Shelf 只负责选中反馈、侧栏收起和代理页透明处理，系统拒绝自由窗时保持普通启动降级。

### 实现约束

- 使用现有 Canvas 和 `ValueAnimator`，不新增动画库。
- 面板和内容由一个共享时间轴驱动，局部进度通过索引和延迟计算，不为每个图标创建 Animator。
- 图标绘制使用 Canvas translate、scale 和 Drawable alpha，逐帧只调用 `postInvalidateOnAnimation()`。
- 窗口几何整数值未变化时跳过 `updateViewLayout()`，避免动画期间重复触发布局。
- `ValueAnimator.areAnimatorsEnabled()` 为 false 时直接呈现最终状态，不执行错峰、缩放和位移。
- 内容列表在一次展开过程中冻结目标高度，刷新结果在动画结束后协调，避免面板中途跳动。

## 错误与降级

- 图标加载失败时保留现有首字母占位符，不阻塞动画或点击。
- 侧栏动画异常时恢复收起状态，应用启动仍执行普通降级路径。
- 版本字符串为空时显示构建默认值，不显示空标签。
- 系统动画关闭或窗口更新失败时保持最终可操作状态，并记录调试日志。

## 测试与验收

### 单元测试

- 版本号资源和 Header 的换行条件。
- 界枢母图形的各资源入口存在且使用统一颜色语义。
- 24dp 触发阈值与 72dp 视觉行程分离。
- 展开、收起曲线对应的局部进度和图标错峰顺序。
- 图标动画起点、终点、索引延迟和 reduced-motion 终态。
- 手机现有行为、滚动、外部点击收起和应用启动回退保持不变。

### 真机验收

- Xiaomi Pad 7S Pro 横屏和竖屏检查设置页标题、版本号、标志不重叠。
- 连续快速展开、收起和点击不同应用，检查没有明显跳帧、窗口几何跳变或图标闪烁。
- 检查 QQ/Notein 等可调整应用的窄自由窗启动，以及不可调整应用的宽窗回退不受影响。
- 临时关闭系统动画验证静态终态，再恢复设备原动画设置。
- 检查启动器全彩图标、Material You 单色图标和通知图标在小尺寸下仍可识别。

## 非目标

- 不引入新的动画框架或后台服务。
- 不改变侧栏内容模式、自由窗能力判断和应用列表数据语义。
- 不试图替换 HyperOS 对第三方自由窗任务的系统级转场。
