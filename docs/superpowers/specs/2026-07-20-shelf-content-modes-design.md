# Edge Shelf 侧栏内容模式设计

## 状态

- 日期：2026-07-20
- 状态：用户已批准设计，等待书面规格确认
- 范围：最近应用模式、固定应用模式、设置界面、数据迁移与刷新策略

## 目标

侧栏提供两种互斥的内容模式：

1. `RECENT`：显示最近使用的可启动应用，新安装和升级后的默认模式。
2. `FIXED`：只显示用户明确选择的固定应用。

切换模式不删除另一模式的数据。用户从最近模式切到固定模式时，之前保存的固定应用原样恢复；切回最近模式时，固定列表继续保留但不参与显示。

## 产品规则

### 最近应用模式

- 手机最多显示 6 个应用，平板最多显示 10 个应用。
- 每次侧栏开始展开时刷新，连续展开采用约 3 秒节流，避免短时间内重复查询系统统计。
- 授予“使用情况访问”后，按系统 `UsageStatsManager` 的最近使用时间排序。
- 系统最近记录不足上限时，用 Edge Shelf 本地启动历史补足；合并时按包名去重。
- 未授予权限、系统查询失败或系统结果为空时，只使用 Edge Shelf 本地启动历史。
- 只显示当前仍已安装且存在可启动 Activity 的应用，并排除 Edge Shelf 自身。
- 该模式不显示 `+`，不会通过侧栏操作自动切换到固定模式。
- 系统使用情况统计表示最近使用的应用，不等同于 Android 最近任务列表。

### 最近模式空状态

当系统最近记录和本地启动历史都没有可显示内容时，侧栏显示一个“最近记录”占位入口。点击后：

- 收起侧栏。
- 打开 Edge Shelf 设置页。
- 设置页显示最近模式说明和“使用情况访问”授权入口。

空状态不会临时显示固定应用，也不会自动改变模式。

### 固定应用模式

- 只按用户保存的固定列表顺序显示可启动应用。
- 侧栏末尾保留 `+`，点击后打开固定应用选择器。
- 设置页显示已选数量和“管理应用”入口。
- 允许保存空固定列表；此时侧栏只显示 `+`。

## 设置界面

在状态卡之后、权限区之前新增“侧栏内容”卡片，沿用现有双按钮选择器视觉：

- `最近应用`
- `固定应用`

`RECENT` 状态说明：每次展开时刷新最近使用的应用。缺少使用情况访问权限时，卡片显示非阻塞提示：“当前显示从 Edge Shelf 打开过的应用”，并提供“允许访问”按钮。权限列表中的使用情况访问在最近模式标记为“建议”，在固定模式标记为“可选”。

`FIXED` 状态说明：只显示用户选择的应用。卡片内显示已选数量和管理按钮；原“本地数据”区域不再重复显示固定应用管理入口。

原“最近启动”数据项改名为“侧栏启动历史”，说明其只用于无权限时的回退。清除操作只清 Edge Shelf 保存的启动历史，不清除 Android 系统使用情况统计。

固定应用选择器标题和说明改为“固定应用”，不在选择器中放置模式切换器。

## 数据模型与迁移

新增：

```text
ShelfMode.RECENT
ShelfMode.FIXED
```

`ShelfSettings` 新增 `mode`，DataStore 新增字符串键 `shelf_mode`。

迁移规则：

- 新安装没有 `shelf_mode` 时默认为 `RECENT`。
- 升级用户没有 `shelf_mode` 时也默认为 `RECENT`。
- 旧固定应用列表完整保留，切换到 `FIXED` 后继续使用。
- 未知或损坏的模式值安全降级为 `RECENT`。

`favorites` 继续保存固定应用有序包名，避免无意义的数据迁移。`recents` 只保存从 Edge Shelf 成功发起启动的本地历史。系统查询到的动态最近列表不写入 DataStore。

当前实现会把固定应用从本地最近历史中排除。双模式启用后必须取消该规则，本地历史应记录所有通过 Edge Shelf 成功启动的应用，否则从固定模式切到最近模式会丢失回退记录。

## 架构与数据流

`EdgeShelfService` 作为动态内容解析的唯一协调者：

```text
侧栏开始展开
  -> 服务执行节流判断
  -> 后台查询 UsageStatsManager
  -> 读取 ShelfSettings 本地历史和模式
  -> 查询可启动应用目录
  -> 合并、去重、过滤、限量
  -> EdgeRailView.updateDisplayApps(...)
```

`EdgeRailView` 不直接查询使用情况权限或系统统计，只负责：

- 绘制服务传入的应用。
- 按模式决定是否绘制 `+`。
- 在开始展开时请求刷新。
- 在最近模式空状态下绘制并响应“最近记录”入口。

服务在以下时机刷新：

- 首次挂载侧栏。
- 切换到 `RECENT`。
- 每次开始展开，受 3 秒节流控制。
- `ACTION_REFRESH`，强制刷新。
- 从权限设置页返回。
- 通过 Edge Shelf 成功启动应用后，更新本地历史并尽快刷新最近模式。

## 错误与降级

- 使用情况访问未授权：仅使用本地启动历史。
- 系统统计查询抛错或返回空：仅使用本地启动历史。
- 应用已卸载、禁用或无启动入口：从最终列表过滤。
- 应用图标加载失败：沿用现有文字占位绘制。
- 查询进行中：保留上一次有效列表，不闪烁为空状态。
- 模式值损坏：使用 `RECENT`，不清除固定列表。
- 固定列表为空：只显示 `+`。
- 最近列表为空：只显示“最近记录”占位入口。

## 测试与验收

### 单元测试

- `ShelfMode` 默认值、保存、恢复和损坏值降级。
- 缺少模式字段时默认 `RECENT`，已有固定列表仍保留。
- 本地历史不再排除固定应用，仍保持去重、时间倒序和上限。
- 固定模式严格保持固定列表顺序。
- 最近模式按“系统统计优先、本地历史补足”合并并去重。
- 未授权、查询异常和空系统结果均降级为本地历史。
- 手机限制 6 个，平板限制 10 个。
- 自身、卸载应用和无启动入口被过滤。
- 展开刷新节流，强制刷新绕过节流。
- 最近模式不显示 `+`，固定模式显示 `+`。
- 两种空状态行为正确。

### 真机验收

- 默认进入最近模式，展开后显示最近使用应用。
- 授权前显示 Edge Shelf 本地历史，授权后包含其他方式打开的应用。
- 连续展开不会明显卡顿或频繁重载图标。
- 切换固定模式后显示原固定列表，`+` 和管理入口可用。
- 切回最近模式时固定列表未丢失。
- 清除“侧栏启动历史”后不声称或尝试清除系统统计。
- 点击最近应用仍以当前自由窗启动链打开，失败时保留普通启动降级。
- 手机和小米平板的 6/10 个数量限制与滚动行为正确。

## 非目标

- 不复制 Android 最近任务界面或任务快照。
- 不持久化系统使用情况统计结果。
- 不新增后台定时轮询。
- 不因权限缺失强制切换模式。
- 不允许最近模式中的占位入口或手势自动修改固定列表。
